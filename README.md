# Ansible Learning Guide

> "I built this guide because beginners deserve better than scattered tutorials."
> — Nkechi Ahanonye, Cloud & DevOps Engineer

A free, beginner-to-advanced Ansible learning guide with real terminal output,
hands-on playbooks, and zero fluff.

## 🌐 Live Site

**[nkydigitech.github.io/ansible-guide](https://nkydigitech.github.io/ansible-guide)**

## ✨ What makes this different

- **Real terminal output** — every module shows exactly what you should see
- **Hands-on exercises** — not just reading, actual commands to run
- **Progressive learning** — each module builds on the last
- **Production-ready** — capstone project builds real infrastructure

## 🚀 Running locally

```bash
pip install mkdocs-material
```
